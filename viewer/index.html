Train chess the smart way.

Open-Chessable is a free, open-source spaced-repetition trainer for chess. Import any PGN, build your repertoire, and review positions right when you're about to forget them. Runs locally, in a native desktop window.

Features

Everything you'd expect from a serious trainer.

No subscriptions. No ads. No tracking. Just a sharp tool that gets out of your way.

Chessable-style SRS

The same deterministic 8-level schedule Chessable uses: 4h → 1d → 3d → 1w → 2w → 1mo → 3mo → 6mo. Get it right, level up. Miss it, back to level 1. No self-rating — the board observes you.

Full course PGN import

Drop in a multi-game PGN. Each [White] (or [Black]) tag becomes a chapter. The parser walks every variation tree and deduplicates transpositions — if 3 branches share 12 opening moves, you only train those 12 once.

Author comments, clickable

Course-author comments render below the board. Move fragments inside them (like "compare 1.d4 d5 2.c4") are clickable and replay on the main board — even when illegal in context, because authors illustrate ideas, not strict lines.

Real Chessable training loop

Play the move on the board. Wrong once → shake + retry. Wrong again → the answer is revealed and you must replay it to continue. Wrong answer = card drops to level 1 immediately. No self-rating — the board observes you.

Dark, focused UI

Built for long study sessions. Linear-inspired dark palette, minimal chrome, zero distractions — just you and the position.

Native desktop app

Powered by pywebview + Flask. Real OS window, real keyboard shortcuts, no Electron, no browser tabs cluttering your workflow.

Local-first, private

Your study data stays in a single SQLite file on your machine. No accounts, no telemetry, no cloud sync — your repertoire is yours alone.

Workflow

From PGN to mastery in four steps.

Create a course

Name your repertoire, pick a color (white, black, or both), and you're ready to import.

Import a PGN

Paste or upload any PGN file. The parser extracts every mainline and variation.

Train what's due

See the position, play the move on the board. Wrong? Get one retry, then the answer is revealed and you replay it. The scheduler watches your moves — no grading yourself.

Watch mastery grow

Each move climbs 8 levels — 4 hours, 1 day, 3 days, 1 week, 2 weeks, 1 month, 3 months, 6 months. Once at level 8 it's burned in. Transpositions are trained once, never repeated across branches.

Quick start

Up and running in 30 seconds.

Requires Python 3.10+. Runs on Linux, macOS, and Windows. The backend is your database; the frontend is just a UI.

# clone & install
git clone https://github.com/jojuega/Open-Chessable.git
cd Open-Chessable
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

# launch the backend (serves both API + frontend on :5000)
python server.py

# …or run the native desktop app (pywebview window)
python app.py

Split frontend / backend

The frontend is a static SPA — host it on Vercel, GitHub Pages, or any CDN. The Flask backend holds your SQLite database and runs wherever you want (your laptop, a Raspberry Pi, a VM). Point the frontend at any backend: 

# open the hosted UI and tell it where your backend lives
https://open-chessable.vercel.app/?api=https://your-tunnel.trycloudflare.com

# expose the local backend through a free tunnel
cloudflared tunnel --url http://127.0.0.1:5000
